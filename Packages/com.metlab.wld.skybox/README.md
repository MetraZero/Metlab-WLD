# レイマーチングでスカイボックスをつくるやつ

`com.metlab.wld.skybox`

時間帯・街の明るさ・視点の高さ・街並み・天気などを選ぶだけで、街の景色のスカイボックス用マテリアルを作るエディタ拡張です。
専用シェーダー（`Metlab/Skybox/City`）が、空・月や太陽・雲・ビルや住宅の明かり・道路・木などを描きます。
画像（テクスチャ）は使わず、視線の先にある街の区画を順にたどる「レイマーチング」という手法で、すべて計算で描いています。

## 使い方

1. メニュー `Tools > Metlab > レイマーチングでスカイボックスをつくるやつ` を開く
2. 時間帯（夜・夕暮れ・昼・明け方）を選ぶ。空・建物・地面の色がまとめてそろう
3. 街の明るさ、視点の高さ、建物の割合、道路、木、天気、空の乗り物などを調整する
4. 「新しく生成」でマテリアルを作る（「上書き」なら指定したマテリアルに書き込む）
5. Lighting ウィンドウの Skybox Material に、作ったマテリアルを設定する

作ったマテリアルを「元にするマテリアル」に入れて「設定を読み込む」と、同じ街の昼版などのバリエーションを作れます。

マテリアルは `Assets/MetlabGenerated/レイマーチングでスカイボックスをつくるやつ/` に作られます。

## 必要なもの

- Unity 2022.3
- com.vrchat.worlds >=3.7.0
