# オブジェクトをランダムにだすやつ

`com.metlab.wld.randomizer`

登録したオブジェクトを、設定した確率で「まとめて」ON または OFF にする UdonSharp スクリプトです。
レアなオブジェクトや、たまにしか出ない演出などに使えます。

- 抽選はインスタンスに最初の1人が入ったときに1回だけ行われ、結果は後から来た人にも共有されます
- 当たり → 登録したものをすべてON、はずれ → すべてOFF
- インスタンスが空になってリセットされるまで、結果は変わりません

## 使い方

1. 常にアクティブな空のオブジェクトに `UdonBehaviour` を付け、Program Source に `MET_ObjectActiveRandomizer` を設定する（このオブジェクト自体は非アクティブにしない）
2. `Probability(%)` に当たりの確率を設定する
3. `Target Objects` に抽選対象を登録する。何も登録しなければ、このオブジェクトの直下の子が対象になる

## 必要なもの

- Unity 2022.3
- com.vrchat.worlds >=3.7.0
