# 昼と夜をきりかえるやつ

`com.metlab.wld.daynight`

ワールド全体の「昼／夜」を全員で切り替える UdonSharp ギミックです。途中から入った人にも、今の状態が反映されます。
空（スカイボックス）は「今いる場所」ごとに変えられ、昼だけ／夜だけ表示するオブジェクトも一緒に切り替わります。

## 中身

| ファイル | 役割 |
| --- | --- |
| `MET_DayNightSystem` | 昼夜の状態（全員で同期）・今いる場所の判定・空の差し替え |
| `MET_SkyboxArea` | 場所1つ分（範囲の箱・昼／夜の空・その場所だけのオブジェクト） |
| `Editor/MET_DayNightSetup` | 作成メニュー |

## 使い方

1. メニュー `Tools > Metlab > 昼と夜をきりかえるやつ > 昼夜システムを作成` を実行する
   - `[MET]昼夜システム` ができる。「どのエリアにもいない時」の昼の空には、今の空が入る
   - 夜の空を設定する
2. 部屋ごとに空を変えたい場合は、部屋のオブジェクトを選んでから `Tools > Metlab > 昼と夜をきりかえるやつ > エリアを追加` を実行する
   - 部屋を囲む範囲の箱（BoxCollider）ができる。箱の中にいる間、その部屋の昼／夜の空になる
3. 昼だけ表示したいもの（照明など）・夜だけ表示したいものを、`[MET]昼夜システム` に登録する
4. ボタンなど別のギミックから、下のメソッドを呼んで切り替える

## 他のギミックから使う

| メソッド | 内容 |
| --- | --- |
| `GetIsNight()` | 今が夜か |
| `_RequestToggle()` | 全員の昼夜を反転 |
| `_RequestDay()` / `_RequestNightMode()` | 全員を昼／夜にする |

「切り替わりを知らせる相手」に入れた UdonBehaviour には、昼夜が変わるたびに `OnDayNightChanged` イベントが届きます。

## 注意

- エリアの範囲が重なっている時は、エリア一覧の上にあるものが優先されます

## 必要なもの

- Unity 2022.3
- com.vrchat.worlds >=3.7.0
