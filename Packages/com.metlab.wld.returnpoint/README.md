# 落ちても元の場所にもどれるやつ

`com.metlab.wld.returnpoint`

> **試作版（BETA）です。** 動作する最小構成の段階で、まれなケースには対応していません。

エラーなどでワールドから落ちたあと、同じインスタンスに入り直したときに、元いた場所へ自動で戻す UdonSharp スクリプトです。
VRChat の Persistence（PlayerData）に、自分の位置・向き・インスタンスの目印・保存時刻を定期的に保存しておき、入り直したときに戻します。

## 戻る条件（すべて満たしたときだけ）

1. 前回の保存データがある（初めて入ったときは戻らない）
2. 保存したときと同じインスタンスに入った（別のインスタンスなら通常のスポーン）
3. 保存してからの時間が「復帰有効時間」（既定30分）より短い

## 使い方

空のオブジェクトに `UdonBehaviour` を付け、Program Source に `MET_PointReturnSystem` を設定してワールドに置くだけで動きます。設定は必要に応じて変えてください。

## 未対応のこと

- インスタンスのマスター自身が落ちて、すぐに入り直した場合などの特殊なケース

## 必要なもの

- Unity 2022.3
- com.vrchat.worlds >=3.8.0
