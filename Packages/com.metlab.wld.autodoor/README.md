# 近づくとひらくドアにするやつ

`com.metlab.wld.autodoor`

プレイヤーが近づくとドアがスライドして開き、離れると閉じる自動ドアの UdonSharp スクリプトです。
Animator を使わずに Transform を直接動かすので、ワールドの軽量化ツールの影響を受けにくく、ドアは何枚でも登録できます。

- 範囲内に誰かがいる間は閉じない
- 閉じている途中で誰かが近づくと、また開く
- プレイヤーの位置だけで判定するので、ネットワーク同期は不要

## 使い方

1. 動かない空のオブジェクトに `UdonBehaviour`（Program Source は `MET_AutoSlideDoor`）と、Is Trigger をオンにした Collider を付ける
2. 「トリガー用コライダー」に、その Collider を設定する
3. 「動かすドア」に各ドアの Transform を登録する
4. 「開くオフセット」に、各ドアが開く方向と距離（ローカル座標）を登録する（「動かすドア」と同じ数にする）
5. 必要なら、開閉の速さ・閉じるまでの待ち時間・効果音を設定する

## 注意

ドアのメッシュが静的バッチやメッシュ結合の対象になると、見た目が動かなくなります。ドアは最適化の対象から外してください。

## 必要なもの

- Unity 2022.3
- com.vrchat.worlds >=3.7.0
